# 智能巡检机器人二维仿真系统

一个最小可运行的 Web 项目：浏览器里用键盘控制机器人在二维地图上移动，机器人状态由后端保存。

这是培训班的初始骨架，用来跑通「前端 → 接口 → 后端 → 状态 → 重绘」这条完整链路。

## 目录结构

```
ai-robot/
├── main.py              后端服务（FastAPI）：状态、移动接口、静态文件
├── requirements.txt     依赖清单
├── 启动.bat             双击启动服务
├── static/
│   ├── index.html       页面结构
│   ├── style.css        样式
│   └── app.js           前端逻辑：读状态、画地图、按键下发指令
└── .venv/               Python 虚拟环境（不提交到 Git）
```

## 怎么启动

方式一：双击 `启动.bat`

方式二：在项目目录执行

```bat
.venv\Scripts\python.exe -m uvicorn main:app --reload --port 8000
```

浏览器打开 <http://127.0.0.1:8000>，用 ↑ ↓ ← → 或 W A S D 控制。

停止服务：在运行窗口按 `Ctrl+C`。

## 接口说明

| 方法 | 路径 | 作用 | 返回 |
|---|---|---|---|
| GET | `/api/state` | 读取机器人当前状态 | 坐标、朝向、步数、地图尺寸、墙体列表 |
| POST | `/api/move` | 下发一次移动 | 新状态 + `blocked` 是否被挡住 |

移动请求体：

```json
{ "dx": 1, "dy": 0 }
```

`dx` 控制左右、`dy` 控制上下，取值只能是 `-1`、`0`、`1`。撞墙或出界时机器人不动，返回 `blocked: true` 和原因。

## 数据流

```
按方向键 → app.js 发 POST /api/move → main.py 校验并改坐标 → 返回 JSON → app.js 重绘 canvas
```

改地图只需改 `main.py` 顶部的 `GRID_W`、`GRID_H`、`WALLS` 三个常量。

## 常见问题

**打不开页面**：先看终端有没有出现 `Uvicorn running on http://127.0.0.1:8000`，没有就说明服务没起来。

**改了代码没反应**：确认启动命令带了 `--reload`；浏览器按 `Ctrl+F5` 强制刷新。

**端口被占用**：把 `--port 8000` 改成 `--port 8001`，浏览器地址也跟着改。
